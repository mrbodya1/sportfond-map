# Карта спорта Югры

Пересобрано 12.11.2026 по паспорту Sportfond с разрешения владельца. Это новая статическая реализация по описанию, а не извлечённая production-копия. Старый дизайн и серверные данные полностью не восстановлены.

## Запуск

Требуется Python 3. Из каталога репозитория:

```sh
python -m http.server 8080
```

Открыть http://localhost:8080. Сборка и npm не нужны. HTML хранится в корне, стили и скрипты — в assets/. Подкаталоги сохраняют адреса страниц.

## Сохранение изменений

```sh
git status
git add <изменённые-файлы>
git commit -m "Описание изменения"
git push origin main
```

Работа считается сохранённой после успешного push и проверки коммита на GitHub. Для крупных изменений используйте отдельную ветку и pull request. Храните также независимую локальную копию репозитория.

## Публикация и откат

В репозитории уже был CNAME; он сохранён. Настройки Pages и DNS в ходе восстановления не изменялись. Перед публикацией проверьте Settings → Pages: источник, ветку, HTTPS и домен. Если Pages публикует main, push в main может обновить сайт автоматически. Документация в этом репозитории публичная.

Откат: найдите нужный коммит через git log, отмените ошибочный через git revert <sha>, затем git push. Не применяйте force push к общей истории. DNS и почтовые MX/TXT меняйте только после отдельной проверки размещения.

## Что отсутствует

Окончательный backend/app.py, data/events.sqlite3, uploads, схема API, правила и авторизация модерации.

Backend в этом репозитории не восстановлен. Интерфейсы входа, загрузки, сохранения заявок и модерации не имитируют успешную работу. Нет вымышленных участников, километров и событий. GitHub Pages обслуживает только статический frontend.

## Резервные копии

Git сохраняет код, текстовые конфигурации без секретов и инструкции. Базы участников, скриншоты, токены, SMTP-пароли и .env сюда не загружать. Для них нужен отдельный зашифрованный backup с проверкой восстановления. Для живой SQLite используйте штатный backup; при извлечении диска сохраняйте существующие WAL/SHM. Проверяйте копию, не оригинал.
